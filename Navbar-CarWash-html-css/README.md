# Sunset Car Wash Website

A responsive business website for a car wash and entertainment venue, built with HTML, CSS, and JavaScript.

The project combines car wash services, food specials, combo deals, and community events into a single user-friendly web experience.

## Features

* Responsive navigation
* Mobile-friendly layout
* Car wash services section
* Special offers and combo deals
* Community events section
* About section
* Interactive navigation using JavaScript
* Responsive design across different screen sizes

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Navbar-CarWash-html-css/
├── img/
├── index.html
├── style.css
└── script.js
```

## Getting Started

1. Clone the repository.
2. Open the `Navbar-CarWash-html-css` folder.
3. Open `index.html` in your browser.

No additional dependencies are required.
